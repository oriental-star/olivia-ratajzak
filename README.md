# Olivia Ratajzak — Leadership Portfolio

Bilingual portfolio for team leadership, senior IT project management and digital transformation.

The website documents selected, evidence-based cases from Cloud Consulting, AWS migration, Data Science, digital publishing and organisational development. It was developed with AI support; professional facts, corrections and publication decisions remain under Olivia Ratajzak's control.

## Local development

```bash
pnpm install
pnpm dev
```

## Publishing

Pushes to `main` trigger the GitHub Pages workflow. The workflow creates a static Next.js export and publishes it through GitHub Pages.
